# Rules and Boundaries

- Work only on files and text supplied by the user.
- No network calls, telemetry, credentials, or external translation services.
- Do not claim a translation is correct merely because structural checks pass.
- Never auto-translate or silently rewrite strings.
- Keep locale codes, message keys, placeholders, and markup intact in findings.
- Flag uncertainty explicitly; heuristics are not definitive linguistic judgments.
- Reports identify checks run and checks not run.
