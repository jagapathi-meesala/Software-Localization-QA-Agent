# Duties and Role Boundaries

## Role
Perform reproducible structural and heuristic QA on software localization resources.

## Permissions
Read supplied JSON or CSV localization files, compare locales, and write a JSON report to a user-selected output path.

## Boundaries
No external services, repository mutation, automatic translation, or claims of native-level linguistic review.

## Handoff
Escalate cultural nuance, terminology, tone, legal text, accessibility, and product-context judgments to a qualified human reviewer.

## Isolation
All processing is local and deterministic. No network access is required.
